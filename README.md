# LBMesh Homebrew Tap

[![brew test](https://github.com/lb-mesh/homebrew-tap/actions/workflows/tests.yml/badge.svg)](https://github.com/lb-mesh/homebrew-tap/actions/workflows/tests.yml)

Official [Homebrew](https://brew.sh) tap for **`lbmesh`**, the Autonomous Local
Infrastructure & Container Orchestration CLI.

- Project homepage: <https://lbmesh.io>
- Source and releases: [`lb-mesh/lbmesh`](https://github.com/lb-mesh/lbmesh)

## Supported platforms

| OS    | Architecture                   |
|-------|--------------------------------|
| macOS | Apple Silicon (arm64), Intel (amd64) |
| Linux | arm64, amd64 (64-bit only)     |

The formula installs a prebuilt binary from the matching GitHub release, so you
don't need a Go toolchain.

## Install

```bash
brew install lb-mesh/tap/lbmesh
```

Or tap once, then install by name:

```bash
brew tap lb-mesh/tap
brew install lbmesh
```

Check that it installed:

```bash
lbmesh --help
```

## Upgrade

```bash
brew update && brew upgrade lbmesh
```

## Uninstall

```bash
brew uninstall lbmesh
brew untap lb-mesh/tap
```

## Repository layout

```

├── Formula/

    └── tests.yml              # CI: brew style, audit, install, and test
```

## How this tap is maintained

`Formula/lbmesh.rb` is generated and pushed by [GoReleaser](https://goreleaser.com)
from the [`lb-mesh/lbmesh`](https://github.com/lb-mesh/lbmesh) release pipeline
on every `v*` tag. Don't edit it by hand, because the next release overwrites your changes.
Pre-release tags (for example `v1.1.0-rc.1`) are not pushed here.

To change the formula (description, install steps, test block), update the
`brews` section of the GoReleaser config in `lb-mesh/lbmesh` instead.

### Continuous integration

Every push to `main` and every pull request runs the
[`brew test`](.github/workflows/tests.yml) workflow on `macos-latest` and
`ubuntu-latest`. It:

1. Lints the tap with `brew style lb-mesh/tap`
2. Audits it with `brew audit --tap lb-mesh/tap`
3. Installs the formula and runs its `test do` block (`brew test lb-mesh/tap/lbmesh`)

To run the same checks locally:

```bash
brew tap lb-mesh/tap
brew style lb-mesh/tap
brew audit --tap lb-mesh/tap
brew install lb-mesh/tap/lbmesh
brew test lb-mesh/tap/lbmesh
```

## Troubleshooting

- **`brew` can't find a new version.** Run `brew update` first so Homebrew
  picks up the latest formula from this tap.
- **Checksum mismatch.** The release assets may have been re-uploaded. Open an
  issue on [`lb-mesh/lbmesh`](https://github.com/lb-mesh/lbmesh/issues).
- **Something else wrong with the CLI?** Report bugs and feature requests on the
  main [`lb-mesh/lbmesh`](https://github.com/lb-mesh/lbmesh/issues) repository.
  Use this repo's issues only for problems with the tap or formula.
